# kintone/rest-api-spec

> [!IMPORTANT]
> This repository is archived and is no longer maintained.
>
> The [OpenAPI](https://www.openapis.org/) Description for the kintone REST API now lives in
> **[kintone/openapi-spec](https://github.com/kintone/openapi-spec)**. The files kept here are frozen
> and no longer describe the current API.

## Where to find the OpenAPI Description

- Repository: [kintone/openapi-spec](https://github.com/kintone/openapi-spec)
- Bundled description, YAML: <https://raw.githubusercontent.com/kintone/openapi-spec/main/openapi.yaml>
- Bundled description, JSON: <https://raw.githubusercontent.com/kintone/openapi-spec/main/openapi.json>

The interactive website that this repository used to publish is taken down. To browse the API, read
the [kintone REST API reference](https://kintone.dev/en/docs/kintone/rest-api/).

## Feedback

This repository is archived, so it takes no issues and no pull requests. For anything about the
current specification, follow the
[feedback guidance in kintone/openapi-spec](https://github.com/kintone/openapi-spec#feedback).
